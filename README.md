# Generate Layered SVG Design

This Python script demonstrates how to programmatically generate a structured SVG file with distinct layers, represented by SVG `<g>` (group) elements. This concept is relevant to modern design workflows, where assets need to be easily editable and transferable between tools like Figma, by maintaining a clear layer hierarchy. The generated SVG can be opened in any vector graphics editor, including Figma, to show its layered structure and editable components.

## Language

`python`

## How to Run

Save the code as `generate_layered_svg.py`. Run `python generate_layered_svg.py` in your terminal. An `layered_design.svg` file will be created, which you can then open in a web browser or a design tool like Figma.
